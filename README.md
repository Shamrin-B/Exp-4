# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:

To develop the Railway Reservation System using Star UML tool.

# SRS (Procedure):
```
Start the system.

User logs in or creates a new account.

User searches for trains by source, destination, and date.

System displays available trains and seat details.

User selects a train and books a ticket.

System stores booking details and generates a ticket.

User can view, update, or cancel the booking.

Admin can add, update, or delete train details.

User logs out.

End.
```
